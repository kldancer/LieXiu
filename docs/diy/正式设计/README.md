## 3. 维护规则

1. 稳定产品语义只在对应权威文档维护；进度板不得复制字段、状态机和安全合同。
2. 新方案未定时可建立临时过程文档；决策稳定后先更新本目录，再删除过程文档。
3. 一项语义只允许一个所有者。跨文档只链接，不平行改写。
4. 单次命令、日志、临时 ID、备份路径、测试通过次数和阶段百分比不进入正式设计。
5. 代码与正文不一致时，以真实实现和测试取证后修正文档；不得用文档掩盖实现差异。
6. 历史来源、不可变 migration 和 Git 记录可以保留 Multica 名称；活跃产品统一使用“列宿 · LieXiu”。
